Cómo funciona

Cada pregunta ejecuta DAX real contra el modelo semántico local

💬

1. Pregunta natural

El usuario escribe en español. Sin sintaxis especial, sin formularios. El modelo entiende el contexto del negocio.

⚙️

2. DAX generado

El modelo escribe la consulta DAX, la ejecuta contra Power BI Desktop vía MCP y valida el resultado. El esquema va embebido en el prompt, así que no explora el modelo antes de cada consulta.

📊

3. Cifra, gráfico o archivo

Según lo que pidas: números formateados, un gráfico renderizado como imagen, o un Excel adjunto. Todo llega al chat, sin abrir Power BI.

Stack técnico

Runtime

  • OpenClaw — gateway de agentes AI, maneja el canal de Telegram nativamente
  • LLM intercambiable — el modelo es un parámetro de configuración, no parte de la arquitectura
  • MCP powerbi-modeling — protocolo de herramientas para ejecutar DAX
  • Power BI Desktop — motor de análisis local con el modelo semántico
  • Skill pbi-adventureworks-dax — esquema y patrones para DAX correcto en el primer intento

Diseño

  • Sin script que mantener — el bot corre como una segunda cuenta de Telegram dentro de OpenClaw
  • Esquema embebido — tablas, columnas y medidas van en el prompt; cero turnos de exploración
  • Reconexión automática — el bot verifica y restablece la conexión al modelo antes de cada consulta
  • Reset diario — sesión limpia a medianoche para acotar el contexto acumulado

Monitoreo

Cada conversación queda registrada con su consumo real. Una automatización de OpenClaw exporta los intercambios nuevos a JSONL cada minuto.

📝

Qué se guarda

Pregunta, respuesta, razonamiento, desglose de tokens (input, output, cache read, cache write, reasoning) y costo, con hora local.

🔍

Consciente de la ruta

No todas las rutas de ejecución reportan lo mismo. El log identifica cuál se usó y marca qué campos son fiables en cada una.

💵

Costo real o estimado

Si el proveedor informa el costo, se guarda tal cual. Si no, se estima con tarifas de catálogo y se etiqueta como estimación — nunca se finge un cero.
