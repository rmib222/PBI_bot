Cómo funciona

Cada pregunta ejecuta DAX real contra el modelo semántico local

💬

1. Pregunta natural

El usuario escribe en español. Sin sintaxis especial, sin formularios. El modelo entiende el contexto del negocio.

⚙️

2. DAX generado

GPT-5.6-luna genera la consulta DAX correcta, la ejecuta contra el modelo de Power BI Desktop vía MCP y valida el resultado.

📊

3. Respuesta directa

El resultado llega formateado al chat. Números con separadores de miles, rangos de fechas, comparaciones. Sin abrir Power BI.

Stack técnico

Runtime

  • OpenClaw — gateway de agentes AI, maneja el canal de Telegram nativamente
  • gpt-5.6-luna — modelo de lenguaje con razonamiento extendido
  • MCP powerbi-modeling — protocolo de herramientas para ejecutar DAX
  • Power BI Desktop — motor de análisis local con el modelo semántico

Observabilidad

  • Log diario JSONL con pregunta, respuesta y thinking
  • Tokens por exchange (input, output, cache, reasoning)
  • Costo en USD por conversación
  • Log en tiempo real — cron cada minuto vía OpenClaw
